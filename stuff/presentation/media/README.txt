PRAMANA DECK - MEDIA TO DROP IN HERE
=====================================

Put files in this folder with exactly these names. The deck finds them on its
own the next time index.html is opened (or refreshed with F5). Until a file is
present, its slide shows a dashed placeholder frame naming the file it wants.

Any of the listed extensions works; the first one found is used.

  demo.mp4            Slide 17 "Demo" (right-hand frame). Optional.
  (or .webm / .mov)   Screen recording of a LIVE run of the motorcycle case:
                      run_web.bat -> http://127.0.0.1:8000 -> paste the facts
                      (they are on slide 17) with offence date 15 August 2024
                      -> let the pipeline view play -> scroll the report.
                      About 60-90 s. Record 1920x1080 (Windows: Win+Alt+R with
                      Xbox Game Bar, or Snipping Tool's video mode). It plays
                      muted and looped when the slide opens; it has controls.
                      Tip: speed the waiting part up 2-4x in any editor (Clipchamp
                      ships with Windows) so the slide holds attention.

  screen-pipeline.png Backup slide 25, top left. The live pipeline view mid-run
  (or .jpg / .webp)   (stages lighting up, sections moving through the ledger).

  screen-report.png   Backup slide 25, top right. The finished report: green verified
                      charges, an amber doubted one if the case has it,
                      precedents and counter-arguments.

  screen-graph.png    Backup slide 25, bottom left. The citation-graph / evidence-map
                      view of a case.

  screen-dashboard.png  Backup slide 25, bottom right. The evaluation dashboard.

All four screenshot frames are 16:9, so a full-window 1920x1080 capture
(Win+Shift+S, then save) fills them exactly. Other shapes are letterboxed,
never cropped.

After adding media, re-export the PDF backup (see ../README.md) so it carries
the screenshots too. Videos cannot play in a PDF; the PDF shows the placeholder.
